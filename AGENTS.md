# hatchward/docs

The website and documentation for hatchward.dev (Jekyll, built by GitHub Pages
from `main`). Read `README.md` first.

- **Generated files:** `errors.md`, `install.sh`, `license.md` and
  `_includes/changelog.md` are written by hatchward/core's release tooling. Never
  edit them here; change them in hatchward/core.
- **This repository is public.** Nothing internal belongs here: no links into
  hatchward/core (it's internal), no internal hostnames, no unreleased plans.
- **Issues** go to the Issue Tracker in the `hatchward/kb` vault, not GitHub Issues.
- Add a new page to `_data/nav.yml` as well, or it won't appear in the navigation.
- Check a change with `bundle exec jekyll build` before opening a pull request.
