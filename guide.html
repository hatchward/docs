hatchward guide

hatchward runs coding-agent work on machines you own. You create an account in the console, connect a project's ticket source and publish it, then enroll a machine; the hosted control plane hands the machine assignments, each in its own container.

Get running in three steps

  1. Sign up Create an account Enter your email at the console and paste the code it sends.
  2. Set up Connect a ticket source and publish a project Notion, Mahfouz or GitHub Projects, connected from Integrations.
  3. Enroll Install the CLI and enroll a machine Paste the one-time code from the console. The machine then waits for work.
