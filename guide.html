hatchward guide

hatchward runs coding-agent work on machines you own. You enroll a machine, connect a project's ticket source, and publish a policy; the hosted control plane then hands the machine assignments, each in its own container.

Get running in three steps

  1. Install Put the CLI on a machine One line on macOS and Linux, or Homebrew.
  2. Enroll Run hatchward Enter the one-time code. The machine then waits for work.
  3. Connect Choose a ticket source Notion, Mahfouz or GitHub Projects, connected from Integrations.
